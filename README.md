# Краткое описание

Скрипт поднимающий web-server на localhost. Отображает текущий статус механической руки. Статус можно менять и он сохраняется в отдельный файл.

## Запуск

1. Убедиться что установлен python3
2. В командной строке прописать: "python3 server.py"

## Управление

1. Посмотреть текущий статус: http://localhost:3000/
2. Уставновить статус в ON: http://localhost:3000/status-on
3. Установить статус в OFF: http://localhost:3000/status-off

## Примечание

В репозитории так же присутствует эскзиз робо-руки для которой был выполнен сервер.
